# Definition of Done — mapNplan

Une tâche est "Done" si:

1. Fonctionnel
- Le besoin décrit dans l’Issue est couvert.
- Les critères d’acceptation sont validés.

2. Qualité
- Lint/format OK.
- Tests unitaires ajoutés et passants.
- Cas d’erreur traités (messages + logs).

3. Revue
- PR relue par Agent QA + 1 humain.
- Commentaires critiques résolus.

4. Exploitation
- Aucun secret en dur.
- Impact perf raisonnable.
- Notes de release prêtes si changement visible.
