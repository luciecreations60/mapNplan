# Upload V0.1 Part 16 to GitHub

1. Extract `travel-planner-v0.1-part16.zip`.
2. In the repository, choose **Add file → Upload files**.
3. Upload the complete extracted content and replace existing files.
4. Commit directly to `main` with:

```text
feat: add v0.1.15 saved places and inspiration library
```

5. Wait for the green check in **Actions**.
6. Refresh Chrome with `Ctrl + F5` or Safari with `Cmd + Option + R`.
