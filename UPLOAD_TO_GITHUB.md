# Upload V0.1 Part 22 to GitHub

1. Extract `travel-planner-v0.1-part22.zip`.
2. Open the GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload the complete extracted contents and replace existing files.
5. Commit directly to `main` with:

```text
chore: add v0.1.21 data resilience and performance
```

6. Open **Actions**.
7. Confirm these steps are green:

```text
Project quality checks
Automated tests
Production build
Build size audit
Upload production artifact
Deploy to GitHub Pages
```

8. Force-refresh the browser after deployment.
