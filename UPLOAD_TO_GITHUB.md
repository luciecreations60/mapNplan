# Upload this version without installing anything

1. Unzip `travel-planner-v0.1-part1.zip`.
2. Open `https://github.com/luciecreations60/travel-planner`.
3. Click **Add file**, then **Upload files**.
4. Drag the full contents of the extracted folder into GitHub.
5. Use this commit message:

   `feat: add v0.1 foundation`

6. Commit directly to `main`.
7. Go to **Settings → Pages**.
8. Choose **GitHub Actions** under **Source**.
9. Go to **Actions** and open the latest workflow run.
10. After the green check mark appears, open the deployment URL.

Do not upload the ZIP itself into the repository. Upload the files and folders contained inside it.
