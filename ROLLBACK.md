# Retour arrière — V0.1.23 rc.2

Avant l’installation, télécharger une sauvegarde JSON complète depuis les paramètres et conserver le ZIP de la Partie 23.

En cas de problème bloquant après déploiement :

1. ouvrir l’historique des commits GitHub ;
2. repérer le commit de la Partie 23 `0.1.22 rc.1` ;
3. utiliser l’option de restauration ou réimporter les fichiers du ZIP Partie 23 ;
4. attendre le nouveau déploiement GitHub Actions ;
5. recharger le navigateur ;
6. restaurer la sauvegarde JSON seulement si les données locales ont été supprimées.

Le passage au schéma 17 ajoute des champs facultatifs. Un retour au code précédent peut ignorer ces champs sans modifier le contenu principal des activités, réservations ou documents. Ne pas effacer les données du navigateur avant d’avoir récupéré une sauvegarde.
