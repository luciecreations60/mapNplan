# Préparation V1 — RC4 mapNplan

## État

La RC4 remplace l’identité provisoire par le nom et le design mapNplan. Le produit reste en Release Candidate jusqu’à validation visuelle sur le site GitHub Pages et vérification des principaux parcours avec les données existantes.

## Conditions avant V1.0

1. workflow GitHub Actions entièrement vert ;
2. absence de perte de données après mise à jour ;
3. logo, navigation et formulaires corrects sur Chrome et Safari ;
4. thème clair et sombre lisibles ;
5. responsive validé sur mobile ;
6. aucun problème bloquant remonté pendant les tests RC4.

Le référencement et le domaine restent hors périmètre jusqu’à la décision de lancement.
